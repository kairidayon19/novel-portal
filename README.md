# ライトノベル作品ポータル

## 起動
VS Code の Live Server で index.html を開きます。

## Google スプレッドシート連携
1. Google スプレッドシートの「拡張機能」→「Apps Script」を開きます。
2. このフォルダの `Code.gs` を Apps Script のコードに貼り付けます（従来の doGet は置き換えます）。
3. 「デプロイ」→「デプロイを管理」→編集（鉛筆）→「バージョン：新バージョン」→「デプロイ」。アクセスできるユーザーは「全員」、実行ユーザーは「自分」にします。
4. 発行された `/exec` で終わるウェブアプリ URL をコピーします。
5. `app.js` の `const GAS_URL = '';` の空文字内に URL を貼ります。
6. Live Server でページを更新して動作確認します。

**重要:** API は一般公開されます。`Code.gs` は「おすすめ一覧」の10列だけを返します。個人情報・非公開情報はこれらの列に入れないでください。URLのリンク先も公開対象です。

Apps Script の ContentService にはブラウザから直接 fetch した際の CORS 制限があるため、ここでは JSONP 方式で読み込みます。JSONP は公開された信頼できる自分の Apps Script URL に限って使用してください。

`GAS_URL` が空の間は、同梱の `books.json` を表示します。`books.json` は旧データのバックアップとして残しています。

## データの前提
シート名：`おすすめ一覧`。1行目が見出し、2行目以降がデータ。A〜J列の順序は、発売年、発売月、作品名、著者、イラスト、レーベル、ジャンル、刊行状況、BookWalkerリンク、Amazonリンクです。

## 公開
GitHub Pages などの静的ホスティングで公開できます。APIの更新はApps Script側の再デプロイが必要です（シートのデータ編集のみなら再デプロイ不要）。
